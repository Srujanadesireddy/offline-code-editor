# Offline-First Collaborative Code Editor

A VS Code-inspired collaborative code editor built using React, Vite, Monaco Editor, and Tailwind CSS. This project is designed to support offline development and collaborative editing in future phases.

---

## 🚀 Features

- VS Code-inspired UI
- Monaco Code Editor
- File Explorer
- File Tabs
- Breadcrumb Navigation
- Search Panel
- Settings Panel
- Profile Panel
- Activity Bar
- Status Bar
- Context Menu
- Auto Save
- Online/Offline Status Indicator
- Toast Notifications
- Local Storage Support

---

## 🛠️ Tech Stack

### Frontend

## 📦 Installation

Clone the repository:

```bash
git clone <repository-url>
```

Move into the client folder:

```bash
cd client
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser:

```
http://localhost:5173
```
